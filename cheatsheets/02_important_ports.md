# Important AWS / Networking Ports

| Port | Protocol/Service | Use |
|---:|---|---|
| 22 | SSH | Linux remote login |
| 80 | HTTP | Web traffic |
| 443 | HTTPS | Secure web traffic |
| 2049 | NFS | EFS access |
| 3306 | MySQL | Common RDS MySQL port |
| 5432 | PostgreSQL | Common PostgreSQL port |
| 3389 | RDP | Windows remote desktop |
