# 18 — CloudTrail Basics

## What is CloudTrail?

The training revision describes **CloudTrail** as recording AWS **API activity**.

**Memory:** CloudWatch = Monitoring | CloudTrail = API Audit.

## CloudWatch vs CloudTrail

- **CloudWatch:** metrics, logs, dashboards and alarms for monitoring/observability.
- **CloudTrail:** records API activity for auditing/tracing actions.
