# 08 — S3 (Simple Storage Service)

## What is S3?

**S3 = Simple Storage Service.** It is AWS object storage.

**Remember:** S3 = Object Storage.

## S3 structure

```text
S3
└── Bucket
    └── Object
```

- **Bucket:** container for S3 objects.
- **Object:** the stored file/data.

## Bucket name

The trainer material and revision notes emphasize that S3 bucket names must be **globally unique**.

## Versioning

S3 Versioning keeps previous versions of objects so older versions can be recovered.

**Remember:** Versioning = file history / recovery.

## Glacier

The revision material describes **S3 Glacier** as an archive storage option for data that is rarely accessed.

**Remember:** Glacier = Archive.

## Static website hosting practical

Trainer revision flow:

1. Create an S3 bucket.
2. Upload `index.html` and `error.html`.
3. For the learning exercise, change Block Public Access according to the lab requirement.
4. Properties → Static website hosting → Enable.
5. Set:
   - Index document = `index.html`
   - Error document = `error.html`
6. Configure the learning-exercise bucket policy.
7. Open the website endpoint from the bucket properties.

## Security note from the training material

For a normal secure bucket creation exercise, the trainer revision keeps **Block all public access ON** and uses default encryption. Public access is only changed for the explicit public-object/static-website learning exercise.

## S3 vs EBS

- S3 = object storage.
- EBS = block storage.
