# AWS Hands-On Learning Map

This repository is organized around the practical work completed during AWS learning.

| Area | Practicals / Concepts |
|---|---|
| Compute | EC2 launch, Linux/Windows, SSH/RDP, AMI, User Data, instance states, instance families and pricing concepts |
| Storage | EBS attach/format/mount/detach, EFS shared mount, S3 objects/buckets, versioning, Glacier/archive concepts |
| Networking | VPC, CIDR, subnets, route tables, IGW, NAT Gateway, Elastic IP, SG, NACL, peering, S3 Gateway Endpoint |
| Load Balancing | ELB, ALB, NLB, listeners, target groups, health checks |
| Scaling | Launch Templates, ASG, Min/Desired/Max, scaling concepts |
| Monitoring | CloudWatch metrics, alarms, dashboards, logs; SNS notifications |
| Databases | RDS, Multi-AZ, Read Replica, DynamoDB keys/query/scan |
| Audit | CloudTrail API activity |
