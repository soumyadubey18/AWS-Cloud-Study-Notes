# 01 — AWS & Cloud Basics

## AWS

**AWS = Amazon Web Services.** It is Amazon's cloud platform providing compute, storage, networking, databases and other services.

**Remember:** AWS = Amazon Web Services.

## Cloud Computing

Cloud computing means getting servers, storage, databases and other IT resources from a cloud provider instead of owning all of the physical infrastructure.

**Remember:** Cloud = use/rent resources.

## Service Models

### IaaS — Infrastructure as a Service
Provides infrastructure such as virtual machines, storage and networking. You manage more of the OS/application stack.

**Remember:** IaaS = Infrastructure.

### PaaS — Platform as a Service
Provides a managed application platform so you focus more on application development and less on platform administration.

**Remember:** PaaS = Platform.

### SaaS — Software as a Service
Provides ready-to-use software over the internet. The provider manages the underlying infrastructure and platform.

**Remember:** SaaS = Software.

## Deployment Models

- Public
- Private
- Hybrid

## Why Cloud / AWS?

Training notes emphasize benefits such as scalability, pay-as-you-go usage, high availability and global access.

## CAPEX vs OPEX

- **CAPEX:** upfront spending on physical infrastructure.
- **OPEX:** operating spending based on ongoing usage/services.
